# Code of Conduct

## The short version

Be decent to people. This is a music player for a phone designed to help people
be on their phones less; nothing here is worth being unpleasant over.

## The longer version

Everyone taking part in this project — issues, pull requests, discussions — is
expected to:

- Treat other people with respect, including when you think they are wrong.
- Accept that maintainers have limited time, and that "no" is a complete answer.
- Assume good faith. Most friction online is a misread tone, not an attack.
- Keep it on topic. This repository is about Amp.

The following are not welcome, and will be removed:

- Harassment, insults, or personal attacks.
- Discriminatory language or imagery of any kind.
- Publishing anyone's private information.
- Deliberate disruption of discussions.

## Reporting

If someone is behaving this way, contact
[@sublunarian](https://github.com/sublunarian) directly on GitHub, or use this
repository's private vulnerability reporting if you would rather it stayed
confidential.

Reports are read by the maintainer. This is a one-person project, so there is no
committee and no process to appeal to — what there is, is someone who will
listen and who can remove comments, close threads, and block accounts.

## Scope

This applies in this repository and anywhere someone is representing the
project.
